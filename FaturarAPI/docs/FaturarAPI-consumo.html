FaturarAPI

Guia para emitir uma fatura no Primavera a partir de PHP. Precisas da extensão cURL.

Endereço: http://localhost:50738. O corpo é JSON. Se o servidor exigir chave, envia o cabeçalho X-Api-Key. Se não exigir, apaga essa linha dos exemplos.

O artigo tem de existir no Primavera. O cliente é criado se o NIF ainda não existir. Não envies a série: a API usa a série por defeito do tipo de documento. O preço é o do artigo; não calcules o IVA no PHP. Vê precoComIva em GET /api/health.

Emitir fatura — POST /api/faturas

tipoDoc e modoPag vão no endereço. Exemplo: fatura FA, pagamento MB. Com iniciarDownload a false, a resposta é JSON e podes lê-la no ecrã, como no Vendus.

<?php
$url    = 'http://localhost:50738/api/faturas?tipoDoc=FA&modoPag=MB';
$apiKey = 'a-tua-chave';
$params = array(
    'ordemServico'    => 'OS-2026-0042',
    'data'            => '2026-10-18',
    'observacoes'     => '',
    'iniciarDownload' => false,
    'cliente'         => array(
        'nif'  => '5410000000',
        'nome' => 'Cliente Exemplo',
    ),
    'linhas' => array(
        array(
            'artigo'        => 'SN002',
            'quantidade'    => 1,
            'precoUnitario' => 5600,
            'desconto'      => 0,
            'codIva'        => '14',
            'unidade'       => 'SACO',
        ),
    ),
);

$curl = curl_init($url);
curl_setopt($curl, CURLOPT_RETURNTRANSFER, true);
curl_setopt($curl, CURLOPT_POST, true);
curl_setopt($curl, CURLOPT_HTTPHEADER, array(
    'Content-Type: application/json',
    'X-Api-Key: ' . $apiKey,
));
curl_setopt($curl, CURLOPT_POSTFIELDS, json_encode($params));
$result = curl_exec($curl);
$http   = curl_getinfo($curl, CURLINFO_HTTP_CODE);
curl_close($curl);

echo $http . PHP_EOL . $result;
?>

Para gravar o PDF, tira iniciarDownload (o omissão já descarrega) e substitui o echo por:

if ($http == 200) {
    file_put_contents('fatura.pdf', $result);
} else {
    echo $result;
}

Nesse caso lê também os cabeçalhos. Acrescenta CURLOPT_HEADER a true e separa o corpo:

$raw  = curl_exec($curl);
$size = curl_getinfo($curl, CURLINFO_HEADER_SIZE);
$head = substr($raw, 0, $size);   // X-Fatura-Referencia: FA 2026/53
$body = substr($raw, $size);
file_put_contents('fatura.pdf', $body);

Resposta JSON (iniciarDownload: false):

{
  "sucesso": true,
  "clienteCriado": false,
  "jaExistia": false,
  "cliente": { "codigo": "SNXS001", "nome": "Cliente Exemplo", "nif": "5410000000" },
  "fatura": { "referencia": "FA 2026/53", "serie": "2026", "numDoc": 53, "totalDocumento": 5600, "estado": "ACTIVO" }
}

No PDF, os mesmos dados vêm nos cabeçalhos X-Fatura-Referencia, X-Fatura-Total, X-Cliente-Codigo, X-Cliente-Criado e X-Fatura-Ja-Existia. jaExistia: true não é erro: é a fatura que já existia para aquela ordem.

Listar — GET /api/faturas

Indica o NIF, o código do cliente, ou as duas datas.

<?php
$url = 'http://localhost:50738/api/faturas?' . http_build_query(array(
    'tipoDoc'    => 'FA',
    'nif'        => '5410000000',
    'dataInicio' => '2026-10-01',
    'dataFim'    => '2026-10-18',
));
$curl = curl_init($url);
curl_setopt($curl, CURLOPT_RETURNTRANSFER, true);
curl_setopt($curl, CURLOPT_HTTPHEADER, array('X-Api-Key: a-tua-chave'));
echo curl_exec($curl);
?>

Detalhe — GET /api/faturas/por-referencia

A referência é FA 2026/53 (tipo, espaço, série, barra, número) e tem de começar pelo mesmo tipoDoc.

<?php
$url = 'http://localhost:50738/api/faturas/por-referencia?' . http_build_query(array(
    'tipoDoc'    => 'FA',
    'referencia' => 'FA 2026/53',
));
$curl = curl_init($url);
curl_setopt($curl, CURLOPT_RETURNTRANSFER, true);
curl_setopt($curl, CURLOPT_HTTPHEADER, array('X-Api-Key: a-tua-chave'));
echo curl_exec($curl);
?>

A resposta traz observacoes e linhas (artigo, descrição, quantidade, preço, desconto, codIva, taxaIva, unidade).

PDF já gravado — GET /api/faturas/pdf

<?php
$url = 'http://localhost:50738/api/faturas/pdf?' . http_build_query(array(
    'tipoDoc'    => 'FA',
    'referencia' => 'FA 2026/53',
));
$curl = curl_init($url);
curl_setopt($curl, CURLOPT_RETURNTRANSFER, true);
curl_setopt($curl, CURLOPT_HTTPHEADER, array('X-Api-Key: a-tua-chave'));
$pdf  = curl_exec($curl);
$http = curl_getinfo($curl, CURLINFO_HTTP_CODE);
curl_close($curl);
if ($http == 200) file_put_contents('fatura.pdf', $pdf);
else echo $pdf;
?>

Anular — POST /api/faturas/anular

<?php
$url    = 'http://localhost:50738/api/faturas/anular?tipoDoc=FA';
$params = array(
    'referencia'  => 'FA 2026/53',
    'motivo'      => 'C06',
    'observacoes' => 'Anulada pelo sistema de origem',
);
$curl = curl_init($url);
curl_setopt($curl, CURLOPT_RETURNTRANSFER, true);
curl_setopt($curl, CURLOPT_POST, true);
curl_setopt($curl, CURLOPT_HTTPHEADER, array(
    'Content-Type: application/json',
    'X-Api-Key: a-tua-chave',
));
curl_setopt($curl, CURLOPT_POSTFIELDS, json_encode($params));
echo curl_exec($curl);
?>

motivo é opcional. Resposta: {"sucesso":true,"referencia":"FA 2026/53","estado":"ANULADO"}.

GET /api/health devolve estado, empresa, moeda e precoComIva. Usa esta chamada primeiro.

Erros

O corpo é {"mensagem":"..."}. No PDF, o campo pode chamar-se message.

HTTPO que fazer
400Corrige o pedido. Artigo inexistente, quantidade, desconto ou referência errada. Não cries o artigo pela API.
401A chave não confere. Envia X-Api-Key em texto.
404Essa consulta não encontrou o registo.
500O Primavera recusou. Se clienteCriado for true, o cliente ficou gravado. Se a mensagem tiver a referência, o documento existe: pede o PDF, não emitas outra vez.
503O Primavera não abriu. Tenta de novo.
